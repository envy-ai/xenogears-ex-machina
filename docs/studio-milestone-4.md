## Architecture and concrete work

Keep game commands separate from Studio::command: the game remains the sole authority for live state, while the studio backend owns read-only event analysis. Introduce focused modules under tools/studio/src/game/ for the common link/controller, native transport, browser transport, schema model and live-PC mapping. Integrate through tools/studio/src/App.tsx and a small explicit selection API in events/EventStudio.tsx. Extend platform/host.ts only for the required native APIs. Reuse editor/DockableWorkspace, DockerList, NumberField, RecordSelect, EditorDialogShell and existing error/log contracts. New feature styling belongs in authoritative SCSS and must be compiled.

1. [ ] Preflight current runtime contracts. Read src/runtime/crates/xem-desktop/tests/control.rs, xem-core/src/control.rs, relevant xem-host control dispatch, src/runtime/web/xem.js, docs/runtime.md Commands/introspection and snapshots, and tools/game_schema.py. Identify the actual pause/run operations and authoritative field actor/PC paths from source/schema. Verify minimal status/step/snapshot/restore/inspect/write on both real hosts before relying on them. Document any needed narrow runtime change before implementing it; do not fake missing capabilities. Retain current runtime behavior for other clients.

2. [ ] Implement the common command boundary and transports. Use JSON command/reply semantics already served by the runtime. Serialize state-mutating requests; make connected/disconnected/busy/error states explicit; reject new work after child/window loss and preserve the original error. Native: spawn an argument array, never shell text; frame stdout by complete lines with partial-read coverage, distinguish stderr, EOF, malformed reply and exit, and stop only the owned child on explicit close. Browser: await existing window.xem readiness and validate the expected API; use run/runFrames for disc-blocked frame work instead of treating the first blocked reply as success. Handle closed windows and same-origin failures explicitly. Do not create a competing simulation or duplicate runtime command interpreter.

3. [ ] Prove deterministic ownership. Pause the host's automatic loop before exact frame commands, inspect/write, snapshot/restore and parity runs. No automatic animation advance may interleave a deterministic sequence. Expose acknowledged running state, not just optimistic button state. Validate positive finite integer frame counts against existing runtime limits, without clamping. Preserve numeric semantics for scalar values, including values not exactly representable as JS numbers. Surface runtime refusal instead of coercing unsupported data.

4. [ ] Build schema inspection around the schema belonging to the attached game module. Resolve how that exact schema is supplied on each host; refuse an absent/mismatched schema rather than silently using another build. The tree lazily expands records/arrays/pointers with bounded depth and explicit unsupported/untyped nodes; read values via inspect. Scalar write delegates to write, then reads back. Display original type/path and errors. Never infer writeability from the display label or allow stale requests from a previous connection to overwrite the current tree.

5. [ ] Connect live field actor PCs to M3 navigation. Determine map/disc identity and actor/event/PC from authoritative live fields, with documented source provenance. Require a matching loaded map/component. Resolve exact instruction owners against the existing graph, preserving aliased event entry ownership; a PC in a gap, absent map, non-field context, unresolved actor or mismatched disc produces a clear unavailable reason, never an invented node. Navigation selects and reveals the existing instruction across list/graph views without altering bytes or dropping names edits.

6. [ ] After mockup approval, implement docked live controls and schema inspector, named session snapshots with explicit restore, connection status/errors and actor navigation. Use existing controls/styles and keyboard conventions; proposed controls: F6 step, Shift+F6 run/pause, a visible snapshot/restore action, Enter to inspect/confirm a value, and an accessible jump-to-node action. Resolve shortcut conflicts against registered commands and text entry. Preserve M3 navigation, Graphite Teal layout, graph ports and 220px vertical spacing. Snapshot names are scoped to the connection; reconnect/restore must invalidate stale views appropriately.
